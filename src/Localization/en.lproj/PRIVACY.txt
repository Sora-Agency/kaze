KAZE · PRIVACY
Sora Agency · Version 1.2 · October 12, 2026

LOCAL ANALYSIS
Kaze uses names, paths, dates, item types and allocated disk space to display the contents of folders you select. It calculates sizes using metadata; the explorer does not open document contents or request iCloud downloads to measure them. Explorer results remain in memory during the session.

Application discovery also reads identifiers and installation metadata to locate related data. Resource views query local Docker and Xcode tools. Cleanup features act on the files and resources described in their controls and confirmations.

DUPLICATES, ASSISTANT AND MONITOR
Smart Scan shares metadata locally across storage views. Exact duplicate detection reads eligible local file contents in bounded blocks to compute SHA-256 hashes. Explicit photo comparison reads eligible images and creates thumbnails for Apple Vision feature prints entirely on the Mac. Cloud providers, backups and Photos libraries are excluded from duplicate candidates; visual similarities are for review only. Quick Look may read the item you explicitly open. Hashes, thumbnails and feature prints stay in memory for the session and are not sent externally.

Assistant AI is optional. Only choosing Download local AI downloads a llama.cpp engine and Qwen model from GitHub, Hugging Face and their distribution servers; they receive your IP address and standard connection metadata. Kaze checks pinned sizes and SHA-256 before use. It does not install or download AI on launch. Questions and a bounded scan summary are processed entirely on your Mac, without transmitting paths, questions or results. The engine runs only during a query, with no persistent server. AI files remain in ~/Library/Application Support/Kaze/AI until manually removed, including after uninstalling Kaze. Temporary query files are removed when finished; responses stay in session memory. AI can make mistakes and cannot perform cleanup: rules and deletion controls remain independent verifications. The menu bar monitor uses the same app process to read filesystem capacity once per minute. Optional low-space notifications require macOS permission; monitor and alert preferences are stored locally. Disabling the monitor stops its timer.

RECOVERY AND STARTUP APPS
Recovery reads APFS source contents and writes copies only to your chosen folder. Its local report contains paths and errors and is never transmitted. The APFS index stays in memory until you close the source. Kaze uses System Events to read or change startup apps only when requested and with macOS Automation permission. It retains disabled app references (name, path and hidden preference) in ~/Library/Application Support/Kaze/Startup/disabled-v1.json so you can enable them again. This record remains until you remove it manually. Kaze does not edit the private macOS background services database.

OPERATION HISTORY
New cleanup operations record dates, paths or resource identifiers, affected allocation, result, rule version and, when available, the Trash destination and change metadata in ~/Library/Application Support/Kaze/Operations. These local records enable restoration without overwriting existing files and may contain sensitive paths. Moving to Trash does not free space; native irreversible actions cannot be undone. Observed free-space changes may include unrelated macOS activity. History, logs and backups remain until you remove them manually, including after uninstalling Kaze.

NO SORA TELEMETRY
Kaze includes no analytics, advertising or automatic transmission of files, folder listings, paths or logs to Sora Agency. No Sora account is required. Fonts are bundled and are not downloaded when the app opens.

UPDATES
Kaze checks for updates on launch and periodically using Sparkle. You can disable automatic checking in the Kaze menu and check manually. Checks and downloads connect to GitHub and its distribution servers, which receive your IP address and standard connection metadata, including Kaze and Sparkle versions in the user agent. Your files, paths and scan results are not transmitted. System profiling is disabled. The app verifies feed and download signatures before installation, and asks you to install and relaunch.

LOGS AND PREFERENCES
Cleanup, uninstallation and resource management activity is logged locally at:
~/Library/Logs/LiberarEspacioMac/limpieza.log

This historical folder name is retained for compatibility with earlier versions. Logs may contain app names, paths, identifiers and system tool messages. The appearance toggle and language selector store their preferences in local macOS preferences. Scheduled task settings (time, free-space condition, categories, notifications and state) are stored in ~/Library/Application Support/Kaze/schedule.json. Each task has its own identifier and cleanup agent under ~/Library/LaunchAgents, installed only when enabled. The app migrates earlier settings and retains a local backup.

The Instalar.command installer preserves a copy of the app and its previous scheduling configuration under:
~/Library/Application Support/Kaze/Backups

ANALYSIS CACHE
Kaze stores metadata from the last Smart Scan and visited folders locally in ~/Library/Application Support/Kaze/Analysis-v1: paths, sizes, dates, file identifiers and duplicate results. This cache contains no file contents and is not transmitted. It is limited to 128 MiB and 32 folders; Invalidation preserves the last Smart Scan baseline; previous records migrate from Library/Caches. Oversized snapshots retain totals with limited detail. The user can remove this baseline and Kaze will measure again. Restored results show their date and do not authorize deletion without a fresh scan. Explorer checks macOS filesystem events and updates changes in the background while its section is visible.

USER CONTROL
You can stop a scan, change folders and grant or revoke Full Disk Access in System Settings. You can disable tasks in Scheduled Tasks or remove them with the uninstaller. The uninstaller retains logs and backups; you can delete them manually if you wish.

Copy Path and Save a Copy write only to the clipboard or your chosen location. They are not transmitted automatically. If you share logs or screenshots to request help, review them first and remove information you do not want to disclose.

EXTERNAL TOOLS
Kaze may open Finder, System Settings or a page you select, and use macOS, Docker, Xcode or installed tools to perform requested actions. Those tools and the operating system have their own policies and may generate logs or communicate according to their configuration. This notice describes Kaze; it does not replace those tools' policies or control operating system diagnostic features.

MODIFIED VERSIONS
This notice applies to the Sora Agency distribution. Third-party modifications may change data handling; review their code and notices before use.
